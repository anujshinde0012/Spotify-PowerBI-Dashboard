# Spotify Data Analysis Dashboard – Power BI

## Overview

This project is an interactive **Spotify Data Analysis Dashboard** created using Microsoft Power BI.
The dashboard analyzes a large Spotify dataset containing information about songs, artists, albums, popularity, release dates, duration, rankings, and other song-related attributes.
The main goal of this project is to transform raw Spotify data into meaningful visual insights through interactive dashboards, KPIs, charts, slicers, and DAX measures.

## Dashboard Pages
The Power BI report contains four interactive pages:
### 1. Overview
Provides a high-level summary of the Spotify dataset.
Key insights include:
- Average song popularity
- Number of unique songs
- Average song duration
- Number of artists
- Songs by artist
- Songs by album type
- Songs by year
- Average popularity by month
- Other overall Spotify statistics

### 2. Artist Analysis
Focuses on artist-level analysis.
Includes:
- Songs by artist
- Artist popularity
- Number of songs released by artists
- Artist-based rankings
- Comparison of artists based on available metrics

### 3. Song Analysis
Provides detailed analysis of individual songs.
Includes:
- Song rankings
- Popularity analysis
- Song duration
- Explicit vs non-explicit songs
- Album information
- Release information
- Top-performing songs

### 4. Trends & Time Analysis
Analyzes Spotify data across different time periods.
Includes:
- Songs by year
- Songs by month
- Average popularity by month
- Monthly song trends
- Release-date analysis
- Year, quarter, month, and day-based analysis

## Dataset
The project uses the **Top-50-World** Spotify dataset.
The dataset contains information such as:
- Song
- Artist
- Album
- Album type
- Release date
- Popularity
- Duration
- Position
- Explicit status
- Year
- Month
- Quarter
- Other calculated fields

The dataset was transformed and prepared before being used for visualization.

## DAX Measures
Several DAX measures were created to calculate important KPIs and analytical metrics.
Examples include:
- Average Popularity
- Unique Songs
- Average Duration
- Artist Count
- Popularity Rankings
- Top Songs
- Songs by Artist
- Songs by Month
- Songs by Year
- Minimum / Maximum Popularity
- Other analytical measures
These measures allow the dashboard to dynamically respond to filters and slicer selections.

## Interactive Features
The dashboard includes interactive elements such as:
- Button slicers
- Date-based filtering
- Month / Quarter selection
- Interactive charts
- KPI cards
- Artist and song analysis
- Dynamic visual filtering
- Drill-through functionality
- Cross-filtering between visuals
Users can interact with the dashboard to explore different aspects of the Spotify dataset.
